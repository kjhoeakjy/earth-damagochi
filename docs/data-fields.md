# 나비야 나비야 — 원본 데이터셋에 위치 말고 무엇이 있나

59마리의 원본 파일을 한 칸씩 열어 본 결과예요. "채워짐"은 실제 값이 들어 있는 칸이고, 비어 있는 칸은 뺐어요.

## 한눈에

| 종류 | 들어 있는 것 | 해당 동물 |
|---|---|---|
| 시각 | 위치를 잰 정확한 시각 (모든 데이터) | 전부 |
| 위치 정확도 | GPS 오차 10m 이하/초과, GPS 정밀도(HDOP), 위성 수 품질지수, 아르고스 정확도 등급, 오차 반경·타원(m), 빛으로 잰 위치의 오차 범위 | 전부 (방식이 다름) |
| 태그 상태 | 배터리 전압(mV), 사망 감지 신호(alive·dead·lost·unknown) | 뻐꾸기·꺅도요·멧비둘기·바닷새 23마리 |
| 동물 정보 | 성별, 포획 당시 나이대, 새끼 동반, 소속 무리, 함께 목걸이 단 개체, 기록이 끝난 방식 | 순록 6마리 (일부는 물범·갈매기·물개) |
| 계절 표시 | 위치마다 연구자가 붙인 여름/겨울 | 순록 6마리 |
| 태그 기종 | Wildlife Computers Mk10, PTT 번호 | 턱수염물범 3마리 |

**없는 것:** 고도, 수온·염분, 잠수 깊이, 심박·체온, 가속도(움직임 세기), 날씨. 뻐꾸기·멧비둘기·바닷새 파일에는 가속도·기온·기압·고도·속도·방향 칸이 있지만 모든 개체가 전부 비어 있어요. 코끼리물범 태그가 잰 수온·염분(CTD)은 우리가 받은 파일에 들어 있지 않아요.

## 데이터셋별 자세히

### ICARUS (국제우주정거장 수신) — 뻐꾸기 6, 꺅도요 2, 유럽멧비둘기 5, 검은등제비갈매기 8, 어센션군함조 1, 푸른얼굴얼가니새 1
- `location-error-text`: 위치마다 오차 `<=10m` 또는 `>10m`. 대부분 `>10m`.
- `mortality-status`: 태그가 움직임을 오래 못 느끼면 보내는 신호. 상태 메시지 15% 정도에만 있음.
  - 뻐꾸기 BED44E: 2021년 12월 6일부터 한자리(탄자니아 남부)에서 `dead` 신호 5번.
  - 꺅도요 B9FE31 (2022년 2월, 중국 광시), BBE6AB (2021년 11월, 중국 허베이): 마지막에 한자리에서 `dead`.
  - 멧비둘기 Menorca2: 6~7월에 한자리에서 `dead`가 떴는데 8월부터 다시 움직였어요. 이 신호가 늘 맞지는 않는다는 뜻이에요. 2022년 1월 마지막 신호도 `dead`예요.
  - 바닷새는 `lost`가 섞여 나오는데, 뒤에 다시 `alive`가 와서 뜻이 분명하지 않아요.
- `tag-voltage`: 태그 배터리 전압 3,600~4,075mV. 시간이 지나며 떨어지는 게 보여요.
- `icarus:timestamp-accuracy`: 시각 정확도 `OK` / `CLAMPED`.
- 학명, 태그 번호, 연구 이름.

### 줄무늬노랑발갈매기 6마리 (Wikelski 외 2015, Movebank)
- 시각·위치·태그 번호·학명만 있어요. 센서 값 없음.
- 논문 기준: 핀란드 번식지 둥지에서 잡은 어른 새.

### 나그네알바트로스 6마리 (adehabitatLT)
- 아르고스 위치. 앞뒤 위치로 계산해 둔 이동 거리·방향·시간 간격만 추가로 있어요 (위치에서 나온 값).

### 갈색사다새 1마리 (ctmm)
- GPS 위치마다 정밀도 `HDOP` (작을수록 정확, 2~10).
- 같은 새의 아르고스 위치 338개도 따로 있어요: 오차 타원(장축·단축·각도), 정밀도.

### 남방코끼리물범 7마리 (aniMotum · foieGras · bsam)
- 아르고스 정확도 등급 `lc`: 3 (250m 이내) · 2 (250~500m) · 1 (500~1,500m) · 0 (1,500m 넘음) · A · B (오차 미정).
- 한 파일(ellie)은 오차 타원(장축·단축·방향, m)까지 있지만 우리 7마리 파일에는 등급만 있어요.

### 북방물개 새끼 1마리 (crawl)
- 아르고스 정확도 등급.

### 고리무늬물범 3마리 (argosTrack · argosfilter)
- 아르고스 정확도 등급. 어른/아성체 구분은 파일 이름에 있어요.

### 턱수염물범 3마리 (crawl, NOAA)
- 아르고스 정확도 등급, 오차 반경(m), 오차 타원 장축·단축·방향(m).
- 태그 기종 `Mk10`, PTT 번호, 배치 이름(EB2011_3000~3002).

### 북대서양긴수염고래 1마리 (adehabitatLT)
- 하루 한 칸. 181일 중 85일만 위치가 있고, 상당수가 1도 단위로 반올림돼 있어요.

### 녹새치 1마리 (xtractomatic)
- 하루 한 번, 햇빛 세기로 계산한 위치와 그 오차 범위(위도·경도 하한·상한). 위도 오차가 대개 ±1.2~1.9도(약 140~210km)로 크고, 경도 오차는 ±0.24도 정도예요.

### 푸른바다거북 1마리 (SDLfilter)
- Fastloc GPS 품질지수 `qi` 4~8 (위치 계산에 쓴 위성 수).

### 산악순록 6마리 (BC 환경부, TidyTuesday)
- 위치마다 `season`: 연구자가 정한 여름/겨울.
- 개체 정보:

| 개체 | 무리 | 포획 당시 나이 | 새끼 동반 | 기록이 끝난 방식 |
|---|---|---|---|---|
| MO_car102 | Moberly | 12~15살 | 아니요 | 목걸이 회수 |
| QU_car110 | Quintette | 8~10살 | 아니요 | 목걸이 회수 |
| QU_car114 | Quintette | 3~5살 | 예 | 목걸이 회수 |
| KE_car128 | Kennedy | 2~3살 | 아니요 | 목걸이 회수 |
| NA_car133 | Narraway | 4~6살 | 아니요 | 기타 (분실) |
| KE_car155 | Kennedy | 5~7살 | 예 | 목걸이 회수, 두 번째 목걸이는 기타 |

- 모두 암컷. 포획 메모에 같이 목걸이를 단 다른 개체 번호가 있어요 (예: QU_car110은 CAR070·075·111과 같은 무리).
- 같은 데이터셋 다른 순록 중에는 사망 원인(늑대·회색곰 포식, 기차 충돌 등)이 기록된 개체가 있어요. 우리 6마리는 사망 기록이 없어요.

## 데이터셋 밖이지만 사실인 값 (지금 화면에서 쓰는 것)
- 나라·바다·호수·지역 이름: Natural Earth 지도에서 위치로 찾은 이름.
- 그날 그곳의 해 높이·낮 길이·해 뜨고 지는 시각, 달 모양: 위치와 시각으로 한 천문 계산.
- 하루 이동 거리, 출발지에서의 거리, 적도·회귀선 통과: 위치 기록으로 계산 (기록 사이 구간은 직선으로 이음).
